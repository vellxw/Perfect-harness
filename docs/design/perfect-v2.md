# Perfect V2 — approved direction and terminal translation

![Approved generative design direction, reduced copy](perfect-v2-direction.webp)

The approved concept is the second, minimal Perfect black-liquid-glass image in the design conversation (`panel_futurista_de_agentes_de_ia.png`). The file above is a reduced 512px WebP copy of that user-approved image, not a replacement design or a screenshot of implemented software. The original supplied raster was 1672x941. It guides composition and material intent; it does not imply that a cell-based terminal can reproduce pixel refraction.

## Composition

One primary surface, a short top bar, current goal, chronological activity, a slim right agent rail at >=130 columns, and a persistent bottom composer. At medium widths the agents become a strip; at 80x24 they remain available through /agents. No left navigation sidebar, administrative cards, CPU/memory widgets or decorative slogan panel. Four-of-ten iterations is a budget counter, never a 40% completion estimate. Verification counts always refer to the current candidate. Multiple concurrent workers of one role remain separate, and the role label never substitutes for the actual model binding.

## Material

Obsidian #050507, raised graphite #131823, thin cool grey borders, restrained lavender #9AAEFF, near-white text #F5F5F7. The main background may use the terminal's default transparency; overlays are opaque enough to remain readable. Windows Terminal owns Acrylic and the optional faint original wallpaper. Mica is a user-level window theme setting; the installer does not edit it globally. A terminal cell grid cannot reproduce the freeform geometry or variable-sized typography in the concept. The implementation is a terminal translation, not pixel parity.

## Motion

Finite cubic-ease overlay entrance (140ms), 100ms braille activity updates only while running, and reduced/off modes. No background animation loop is needed when the engine is idle. Transition state is presentation-only. A spinner is not evidence of model progress. Animation timings are independent from the agent scheduler. The V2 does not impose an artificial splash delay before the composer.

## Identity

Four curved paths converge on a central verified node. Reproducible SVG masters and a simplified 16–32px variant generate PNG/ICO assets; no font files are embedded or distributed. The wordmark is vector paths. The subtle wallpaper is original vector geometry, not copied stock artwork.

## Screenshot provenance

`capture-tui.mjs` runs the real OpenTUI native renderer and React app, captures its cells/colors and rasterizes those spans. Every image is labeled synthetic display fixture; it is not an operating-system screenshot and does not prove personal-provider inference. OS captures, when available, are labeled separately with the actual OS, commit and host terminal. Native capture rasterization preserves whitespace and bold attributes; platform fonts can still differ.

Acceptance requires keyboard navigation, visible composer at each breakpoint, the newest repair/DONE event remaining visible, clear blocking reasons and exact model metadata in /agents. A beautiful screenshot does not override failing functional tests.
