# Perfect V2 — approved direction and terminal translation

The approved concept is the second, minimal Perfect black-liquid-glass image in the design conversation (`panel_futurista_de_agentes_de_ia.png`). It is a generative concept, not evidence of implemented software. The original raster has not been copied into this repository; the following specification preserves its accepted layout and material intent without representing a substitute as the original image.

## Composition

One primary surface, a short top bar, current goal, chronological activity, a slim right agent rail at >=130 columns, and a persistent bottom composer. At medium widths the agents become a strip; at 80x24 they remain available through /agents. No left navigation sidebar, administrative cards, CPU/memory widgets or decorative slogan panel. Four-of-ten iterations is a budget counter, never a 40% completion estimate. Verification counts always refer to the current candidate.

## Material

Obsidian #050507, raised graphite #131823, thin cool grey borders, restrained lavender #9AAEFF, near-white text #F5F5F7. The main background may use the terminal's default transparency; overlays are opaque enough to remain readable. Windows Terminal owns Acrylic and the optional faint original wallpaper. Mica is a user-level window theme setting; the installer does not edit it globally. A terminal cell grid cannot reproduce the pixel refraction, freeform glass geometry or variable-sized typography of the image. The goal is an honest terminal translation, not a claim of pixel parity.

## Motion

Finite cubic-ease overlay entrance (140ms), 100ms braille activity updates only while running, and reduced/off modes. No background animation loop is needed when the engine is idle. Transition state is presentation-only. A spinner is not evidence of model progress. Animation timings are independent from the agent scheduler.

## Identity

Four curved paths converge on a central verified node. Reproducible SVG masters and a simplified 16–32px variant generate the PNG/ICO assets; no font files are embedded or distributed. The wordmark is vector paths. The subtle wallpaper is original vector geometry, not a copied stock image.

## Screenshot provenance

`capture-tui.mjs` runs the real OpenTUI native renderer and React app, captures its cells and colors, and rasterizes exactly those spans. Every image is labeled synthetic display fixture; it is not an operating-system screenshot and does not prove personal-provider inference. OS captures, when available, are labeled separately with the actual OS and host terminal.

Acceptance requires keyboard navigation, visible composer at each breakpoint, the newest repair/DONE event remaining visible, clear blocking reasons, and exact model metadata in /agents. A beautiful screenshot does not override failing functional tests.
